# 📚 AI-Powered Semantic Research Paper Search Engine

An intelligent research paper search engine that leverages Natural Language Processing (NLP) and Large Language Models (LLMs) to perform semantic search, summarize research papers, extract keywords, recognize named entities, and compare research articles.

Unlike traditional keyword-based search systems, this project understands the semantic meaning of a user's query, enabling more accurate and relevant research paper retrieval.

---

## 🚀 Features

- 🔍 Semantic Search using Sentence Transformers
- 📄 Research Paper Retrieval with FAISS Vector Database
- 📝 Automatic Research Paper Summarization
- 🏷️ Keyword Extraction using KeyBERT
- 🧠 Named Entity Recognition (NER) using spaCy
- 📊 Research Paper Comparison
- 🤖 AI-powered Research Assistant
- ⚡ Fast Similarity Search

## 📖 How It Works

1. Load the research paper dataset.
2. Generate sentence embeddings using Sentence Transformers.
3. Store embeddings in a FAISS vector index.
4. Accept a user query.
5. Perform semantic similarity search.
6. Retrieve the most relevant research papers.
7. Generate summaries using BART.
8. Extract keywords with KeyBERT.
9. Identify named entities using spaCy.
10. Display results in a structured format.
